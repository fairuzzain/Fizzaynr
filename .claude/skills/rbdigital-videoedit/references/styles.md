# Styles: Menu, preset Auto, resipi

## Preset Auto (setiap preset = gabungan style Menu)
**Preset style** (cadang satu, tanda Recommended; setiap preset = gabungan style Menu):
- A. Clean: caption + cut + zoom sikit (asas #7 versi ringan)
- B. Reels Energetik: caption besar, punch-in, pop-up, SFX, music (#7 + #18)
- C. Explainer: motion graphic untuk senarai/nombor, split screen (#10 + #20)
- D. Cutout Pro (Recommended untuk grab attention): text besar BELAKANG badan + icon 3D keliling badan + motion graphic + caption pelbagai style + SFX + music (#1 + #6)
- E. B-roll: potong ke visual lain masa dia bercakap, suara jalan terus; boleh campur dengan D (library.md B-roll)
- F. Premium Editorial: palette brand, serif, effect ikut ayat (#21)
Boleh juga cadang mana-mana nombor Menu kalau lebih sesuai dengan topik.

## Resipi per style


1. **Text Behind**: `.big{top:240-505px;font-size:250px;letter-spacing:-8px;font-weight:800}` dengan titik oren `<b>.</b>`, ATAS `#vid` BAWAH `#cut`; header kecil di atasnya 50px. Huruf bawah bertindih kepala 60-100px; perkataan ≥7 huruf kecil ke ~205px. Slam in (scale 1.5→1, power4.out) + slow push 1→1.06. Max ~8 big word / 20s. Font bertukar ikut peranan perkataan: setiap `.big` dapat class `.f-<nama>` dari `fonts.css` (set font dari Font Library, dipasang dengan `scripts/fonts.py`), contoh `.big.f-anton` biasa, `.big.f-bangers` emosi, `.big.f-dela-gothic-one` hook/CTA. Jangan set `font-family` tetap dalam `.big`. Caption typing `top:1230px`, bg rgba(20,14,12,.55). Pop-up kad prompt gelap (chips Default/Add repository, teks menaip, butang oren, "Copied ✓"), step badge kiri atas (kotak nombor + pill putih, `tl.set('#bnum',{textContent:n},t)`), kad profile CTA (avatar crop footage, "user Nasarudin", butang "link dekat bio" + tap ripple).
2. **Background Swap**: `#vid` opacity 0, `#cut` atas latar baru (gradient, grid, bilik 3D CSS, gambar user). Bayang lembut bawah badan (radial gradient gelap) + light wrap (`drop-shadow` warna latar). Boleh tukar latar ikut seksyen.
3. **Pop-out Frame**: `#stage` jadi kad (scale 0.78, bucu 60px, border putih); `#cut` LUAR kad, transform sama tanpa clip, clip-path `inset(0 0 X% 0)` supaya hanya kepala/tangan terkeluar. `#ground` warna brand.
4. **Outline Glow**: duplikat `#cut` di belakang dengan beberapa `drop-shadow(0 0 0 #fff)` arah berbeza (outline) atau `drop-shadow(0 0 18px #5fe1ff)` (neon), glow pulse pada keyword. Untuk hook 3s + punchline.
5. **Clone**: 3 salinan `#cut` (scale 0.55, x -300/0/+300) muncul satu-satu bila sebut "1, 2, 3"; latar #ground; label nombor atas setiap clone.
6. **Ikon Terbang**: icon dari sheet library.md atau SVG bina sendiri (jangan logo brand sebenar tanpa fail user). Slot: TL (25,600), TR (805,600), ML (15,950), MR (815,950), 230-270px. Masuk dari besar (scale 2.2, rotation ×3 → 1, `E.snap` 8 f, hero sahaja `E.settle`), terapung yoyo y:-18, glow radial, drop-shadow; dua lapis (belakang & depan `#cut`), orbit guna nilai sin/cos tetap. Icon "dah tak perlu" dapat badge X merah.
7. **Karaoke Bold**: 2-4 perkataan, Anton/Montserrat 900 110-130px UPPERCASE, stroke hitam 10px, y≈1150; perkataan aktif kuning #ffcf3a + scale 1.15; icon kecil atas keyword. Jump-cut zoom setiap ayat.
8. **Kinetic Typography**: `#cam` scale 0.35 ke sudut bawah kanan (bulat, border putih); setiap ayat jadi blok text penuh skrin (perkataan masuk satu-satu, saiz ikut penting, slide/rotate antara ayat). Latar gelap + aksen bertukar per ayat.
9. **Cinematic Subtitle**: letterbox 2.35:1 masuk perlahan, grade teal-orange, caption serif 44px putih bawah tengah fade, title card letter-spacing 20px. SFX minimum.
10. **Split Screen**: `#cam` atas (crop muka, tinggi 960), panel bawah: screenshot user (Ken Burns) atau grafik code (senarai, carta, kad). Garis pemisah oren + label kecil.
11. **Green Screen Komen**: latar = screenshot artikel/tweet/website (zoom & highlight bahagian disebut dengan kotak oren), `#cut` kecil (scale 0.6) bawah kiri. Tiada screenshot → kad rekaan berlabel jelas "contoh".
12. **Podcast**: latar gelap + nama show; video dalam frame bulat/kotak; waveform: pre-compute amplitud per frame ke JSON (python + soundfile), bar SVG `scaleY` dengan `tl.set` per frame; lower third nama + topik; caption bawah.
13. **Zoom Class**: slide HTML besar tengah, `#cam` kotak kecil kanan atas dengan nama; slide bertukar ikut point. Kelas penuh → cadang skill video-ajar-zoom.
14. **Documentary**: grade pudar + grain, lower third nama/lokasi (garis + text slide), date stamp typewriter (Special Elite), B-roll Ken Burns, fade hitam, caption serif.
15. **Breaking News**: banner merah "BREAKING NEWS" + headline kuning dari kiri, ticker bawah (`x` linear), logo rekaan "RB NEWS", "LIVE" berkelip. Jangan tiru logo stesen TV sebenar.
16. **Retro VHS / Glitch**: grade VHS, scanline (repeating-linear-gradient), "● REC" + timestamp VT323, glitch slice (clip-path + `x` jitter tetap) pada keyword, chromatic split (2 salinan video berwarna, mix-blend screen, offset 6px).
17. **Scrapbook**: caption atas kertas koyak (clip-path, bg #fdf6e3) + tape (rect separa lutsinar, rotate), stiker bulat, doodle SVG `stroke-dashoffset`. Permanent Marker.
18. **Meme Cut**: zoom laju 1.6× ke muka (0.1s) + shake; freeze frame (`<img>` dari ffmpeg 0.5-1s); text reaksi ("BRUH", "HAH?"); SFX boom. Jarang, 2-3 kali / 20s.
19. **Fake Chat**: bubble WhatsApp/iMessage (#dcf8c6 / #0b84ff) satu-satu di separuh bawah, typing indicator 3 titik dulu, tick biru, avatar kecil, nama kontak rekaan.
20. **Data / Infographic**: nombor → counter (`tl.set` textContent langkah tetap, contoh 20 langkah), bar tumbuh (scaleY), pie (stroke-dasharray), tick. Kad gelap separa lutsinar sebelah muka.
21. **Editorial / Magazine**:
    - Palette: gelap + terang + aksen. Default hijau #16382b, krim #f3ecdc, emas #c9a45c; warna brand user kalau ada. Semua kad, caption, tajuk pakai palette ni sahaja.
    - Font: serif (Instrument Serif / Playfair 400-600, italic untuk perkataan emosi) + Inter Tight 800 UPPERCASE letter-spacing -2px; campur dalam satu tajuk ("BIGGER" sans + "captions." serif italic).
    - Caption Serif Karaoke (library.md Caption #13): kotak hijau gelap (padding 6px 14px, bucu 4px), 52px, `top:1240px`, 3-5 perkataan; belum sebut `rgba(243,236,220,.45)`, dah sebut krim penuh (`tl.set` warna per perkataan). Tiada stroke, tiada bounce.
    - Hook (0-3s): `#ground` hijau penuh, `#cam` mengecil (scale 0.9, y +80) atau kekal, tajuk serif besar 3 baris bertukar ikut ayat (`y:40→0, opacity`, 0.35s power3.out) + timecode monospace `00:00:01:14` berjalan; lepas hook `#ground` slide keluar.
    - Text behind serif 260-300px krim, masuk huruf demi huruf (`clip-path inset` dari kanan), 3-5 kali sahaja.
    - Transition antara angle/take: cut terus + punch-in 1.06 atau whip blur 0.15s; jangan dissolve panjang.
    - CTA: kotak krim "Komen 'EDIT' dan aku hantar walkthrough", input menaip "EDIT" → hati merah → reply "Sending it 📩"; kad profile "Follow" → "Following".

Campur style: asas dari style utama, elemen style kedua pada seksyen tertentu (1+19: text behind untuk hook, fake chat untuk dialog; 21+20: editorial + counter).
