# Lisensi font pack

Semua keluarga font di folder ini berlisensi **SIL Open Font License 1.1** (teks lengkap: `OFL.txt`), diambil dari paket @fontsource (Google Fonts).
Boleh dipakai di video komersial dan ikut dibagikan bersama skill. Tidak boleh dijual sebagai font berdiri sendiri.

- Poppins
- Plus Jakarta Sans
- Montserrat
- Urbanist
- Outfit
- Sora
- Manrope
- Space Grotesk
- Inter
- Instrument Serif
- DM Serif Display
- Fraunces
- Bodoni Moda
- Cormorant Garamond
- Playfair Display
- Anton
- Bebas Neue
- Archivo Black
- Unbounded
- Syne
- JetBrains Mono

Font berbayar milik user tidak boleh dimasukkan ke folder ini kalau skill akan dibagikan.
