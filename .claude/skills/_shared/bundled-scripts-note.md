## Bundled scripts (local)

Each skill's scripts are on this machine at `$ROOT/.claude/skills/<skill>/scripts/`.
There is no Higgsfield sandbox: run them locally (`python "<path>"`, `.sh` via Git Bash `bash "<path>"`).
Any `$HF_WORKFLOWS/<skill>/scripts/...` or bare `scripts/...` path means that local folder.
Write outputs to the project folder, never next to the scripts. Full mapping: `nexabot-routing.md`.
